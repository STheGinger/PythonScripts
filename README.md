# PythonScripts
Hello! Welcome to my collection of Python scripts. 
Most of these scripts are small projects meant to automate parts of my life, solve minor itches, or simply experiment with an idea when inspiration hits. As a result, this repository is a bit of a mixed bag.

Because of that, I've adopted a very simple development process:
1. Make it work.
2. Make it work correctly.
3. Make it robust.
4. Make it pretty.

Not every script is at step 4 yet, and a lot of them aren't even close.
